## Profile checklist (do once, matters more than the posts)

- [ ] Primary category: "Legal services" or the closest practice fit; add
      secondary categories for each line GBP offers
- [ ] Services section: one entry per practice line, with the flat-fee
      framing ("Flat-fee debt lawsuit defense", etc.) — only fees Mike has
      committed to
- [ ] Description: 750 chars using the positioning language (price certainty,
      honest screening, start online); include principal-office city
- [ ] Photos: office exterior/interior, Mike's professional headshot —
      profiles with photos get dramatically more clicks
- [ ] Booking/website links: main site + direct /intake link
- [ ] Q&A section: seed it yourself with the five most-asked questions (one
      per practice line) and answer them — anyone can ask; you want your
      answers ranking first
- [ ] Review flow: closing letters include the review link; NEVER incentivize
      or script reviews
