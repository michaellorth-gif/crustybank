# Expunction / Nondisclosure Intake

## Identity (required in the petition — collect exactly)
- Full legal name (and name at time of each arrest, if different)
- Sex, race, date of birth
- Driver's license number (state), Social Security number
- Current address; address at the time of each arrest

## For EACH arrest (repeat block)
- Date of arrest; county and city
- Arresting agency (PD / SO / DPS / constable)
- Offense(s) charged and level (Class C/B/A, felony degree) — as charged, not as it felt
- Was a charging instrument filed? (ticket/complaint/information/indictment)
- Court and cause number (if charged)
- Disposition, per client: [never charged / dismissed / acquitted / deferred
  adjudication completed / probation completed / convicted / pretrial diversion
  completed / veterans or mental health court / still pending]
- Date of disposition
- Any other charges from the SAME incident (esp. any felony)? Anyone else arrested?
- Any bond forfeiture or failure to appear on this case?
- Prior expunction or nondisclosure ever granted? (once-only rules apply to some routes)

## Records (the screen is not final until these are in the file)
- [ ] DPS criminal history record (client can pull via DPS website, or we run FACT
      clearinghouse fingerprint check)
- [ ] County/district clerk docket printouts for each charged case
- [ ] Judgment/dismissal/discharge orders for each disposition

## Client counseling notes (document that these were covered)
- Expunction = destruction; nondisclosure = sealing visible to government/licensing
- Private background vendors may need follow-up disputes even after the order
- Flat fee covers: screen + one petition per quoted arrest + unopposed hearing;
  contested hearings / State opposition are a separately quoted tier
- Timeline expectation: filing to signed order commonly 30–90 days, county-dependent

## Conflicts & engagement
- Conflict check (client, co-arrestees, victims if any)
- Limited-scope engagement letter signed; fee paid
