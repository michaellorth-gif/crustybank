# Debt-Defense Intake

Collect every field. Items marked ⚑ change the legal analysis — never guess them.

## The lawsuit
- ⚑ Court (JP precinct / county court # / district court #), county, cause number
- ⚑ Date client was SERVED and how (personal, substituted, certified mail) — look at
  the citation; if not served, how did the client learn of the suit?
- ⚑ Has any deadline already passed? Any default judgment signed?
- Plaintiff name exactly as pleaded; plaintiff's law firm
- Amount pleaded (damages, interest, attorney's fees)
- Is the petition verified / styled as a "sworn account"? Affidavits attached?
- Causes of action pleaded (account stated, breach of contract, sworn account, etc.)

## The debt
- ⚑ Original creditor and account (last 4 digits if known)
- ⚑ Does the client recognize the debt? (yes / no / unsure / identity theft)
- ⚑ Approximate date of LAST PAYMENT and date the account went into default
- Charge-off date if known (from credit report)
- Any prior settlement, payment plan, dispute, or 1099-C on this account
- Any bankruptcy filed or planned (STOP — refer to bankruptcy analysis if yes)
- Other collection contacts on this debt: letters, calls, texts (keep everything —
  potential TDCA/FDCPA evidence); was suit threatened before filing, and when?

## The client (settlement & exemption posture)
- Employment status and income source (wages / 1099 / SS / disability / retirement)
- Homeowner or renter; homestead claimed?
- Bank accounts: which banks, approximate non-exempt balances
- Non-exempt assets of significance (second vehicles, boats, rental property...)
- Other pending suits or judgments
- Client goals: fight / settle cheap / payment plan / protect credit / just make it stop

## Conflicts & engagement
- Conflict check run against plaintiff, original creditor, and law firm
- Limited-scope engagement letter signed; fee tier selected; fee paid
- Client contact info verified; preferred contact method

## Immediate outputs (produce at end of intake)
1. Answer deadline (show the computation)
2. Court classification (JP debt-claim / county / district)
3. Limitations flag (time-barred? borderline?)
4. Plaintiff classification (debt buyer / original creditor / servicer)
5. Recommended answer paragraphs + recommended posture (fight / settle / counterclaim-screen)
