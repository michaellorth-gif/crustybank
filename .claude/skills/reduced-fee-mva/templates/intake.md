# Reduced-Fee MVA Intake

## PART A — The wreck
- Date of accident (SOL clock — exact date required)
- County / city / roadway
- Liability scenario: [rear-ended / other driver cited / other driver DWI /
  other driver left turn or red light / disputed / client cited / hit-and-run / other]
- Was the client cited for anything? Does the client believe they share ANY fault?
- Police report obtained? (crash report ID / agency)
- Vehicles: client's and other driver's; commercial vehicle involved?
- Passengers or other claimants competing for the same limits?

## PART B — Injuries & treatment
- Severity band: [soft tissue / fractures / surgery or surgical recommendation /
  catastrophic] — fatality anywhere in the wreck?
- Treatment status: [not started / treating / complete]; gaps in treatment?
- Providers so far (ER, urgent care, chiro, ortho, imaging) — name + city each
- Client is a minor? (tolling + settlement approval — escalate)

## PART C — Coverage map (the case IS the coverage)
- Other driver: name, liability carrier, claim number if opened, limits if known
- Client's auto carrier and policy: UM/UIM? PIP or MedPay? (pull the dec page)
- Health insurance: [none / private / Medicare / Medicaid / ERISA self-funded /
  unknown] — drives the lien plan
- Hospital lien filed or expected? (Tex. Prop. Code ch. 55)

## PART D — Risk screens
- Recorded statement already given to any adjuster?
- Prior attorney on this case? (fee lien — escalate)
- Prior accidents / preexisting conditions in the same body parts (disclose early,
  never hide)
- Client's goals and expectations set: reduced fee = streamlined workflow, not
  reduced effort; conversion to standard fee if suit is filed

## Gate output
- SOL date (accident + 2 years) and days remaining; 90-day decision point calendared
- Track: [REDUCED-FEE ELIGIBLE / STANDARD-FEE TRACK because ___ / ESCALATE because ___ / DECLINE because ___]
- Signed reduced-contingency agreement + HIPAA authorizations collected
- Conflict check: client, other driver, both carriers
